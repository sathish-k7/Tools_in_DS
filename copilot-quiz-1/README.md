# Copilot Quiz

This project is a simple quiz application that tests knowledge about the national animal of India.

## Project Structure

```
copilot-quiz
├── index.html
└── README.md
```

## index.html

The `index.html` file contains the HTML structure for the quiz, including the question "What is the national animal of India?" and multiple choice options: "Tiger", "Lion", "Elephant", "Peacock", and "Bear". The correct answer is "Tiger". The file includes basic styling and JavaScript to handle answer validation and feedback.

## How to Run the Quiz

1. Open the `index.html` file in a web browser.
2. Select an answer from the options provided.
3. Click the submit button to see if your answer is correct.

## Additional Information

- This project is designed to be simple and easy to understand.
- You can modify the questions and options in the `index.html` file to create your own quizzes.
- Feel free to enhance the styling and functionality as needed.
